Detailed Description

template<size_type __first, size_type... __rest>
class ten::shape< __first, __rest >

Handles static, dynamic, and mixed shapes of a given rank. Static dimensions refers to dimenions known at compile time. Dynamic refers to dimensions known at runtime.
